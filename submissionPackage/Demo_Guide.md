# AEGIS — Demonstration guide

[Illustrated PDF with game screenshots](AEGIS_Demo_Guide.pdf)

**Entry point:** [Play AEGIS](https://aloualou56.github.io/argus_trackA/). Select English and choose Delos at the Catastrophic level. Allow around five minutes for the main sequence, then explore the heritage interpretation and observation features.

1. **Choose the site and read its story.** Select Start, complete or skip the opening quiz, and read the guardian's introduction. Select See the dangers.
2. **Design a monitoring network.** Inspect the three threats and available sensor cards. Add a soil moisture probe and a rain gauge for the illustrated example. Position the sensors using the map controls, inspect the remaining coins, and select Done.
3. **Interpret the recorded alarm.** Watch the replay and read the event date, principal signal and detection result. The illustrated Delos example uses the ARGUS AI alarm of 31 August 2026, associated with moisture beneath a mosaic. Select Show me what ARGUS did.
4. **Compare and reflect.** Inspect the proposed network alongside ARGUS's installed instruments. Select See my score and review threat coverage, alarm detection and useful expenditure. Use the available improvement control to compare a changed design.
5. **Explore conservation consequences.** From the results, open an available monument or consequence view. Move the years control and read the explanations. Deterioration effects are authored educational illustrations.
6. **Record an observation.** Open the observation-report feature, choose the site and observation type, and inspect location, description and export/contact options. Review a sample locally.

The screenshots show one retained English demonstration route. Feedback depends on the mission and selected sensors.
